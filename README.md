# 찌멍 · 찜멍

말 걸지 않아도 되는, 그냥 멍하니 머물다 가는 3D 웹 공간 두 곳.
서버에 올리면 **같은 공간을 여러 명이 함께** 걸어 다녀요 (채팅 없음). 파일을 그냥 열면 혼자 걷기만 돼요.

| 사이트 | 파일 | 한 줄 소개 |
|---|---|---|
| 🎣 **찌멍 · 새벽 저수지** | `public/fishing/index.html?place=lake` | 좌대에 앉아 찌를 바라보다 찌올림에 챔질 |
| 🎣 **찌멍 · 얼음 호수** | `public/fishing/index.html?place=ice` | 얼음 구멍에 줄을 내리고 빙어 낚기 |
| ♨ **찜멍 · 동네 찜질방** | `public/jjimjilbang/index.html` | 불가마 땀 빼기, 이마로 계란 깨기, 식혜, 얼음방 |

`public/index.html`은 세 곳으로 가는 입구 페이지입니다.

## 실행 · 배포

```bash
npm install
npm run dev      # http://localhost:8787  (브라우저 창 두 개로 열면 서로 보여요)
npm run deploy   # Cloudflare에 올리기 → https://jjimeong.<계정>.workers.dev
```

- 구조: Worker 하나(`src/index.js`)가 화면 파일(`public/`)과 실시간 연결(`/ws`)을 함께 맡아요.
- 방 하나 = Durable Object 하나 (SQLite 기반, WebSocket Hibernation API → 무료 플랜).
  장소별로 방이 따로예요(`lake` / `ice` / `jjim`). 한 방 30명이 차면 다음 방으로 자동 배정.
- 주소 끝에 `?room=이름`을 붙이면 친구끼리만 그 방에서 만나요. 예: `/fishing/?place=lake&room=우리동네`
- 위치·방향·동작을 바뀌었을 때만 최대 1초에 10번 보내요. 가만히 있으면 아무것도 안 보내요.
- 연결이 끊기면 몇 초 뒤 자동 재연결, 그동안에도 혼자 걷기는 그대로.
- 무료 한도: 하루 요청 10만 건(실시간 메시지 20개 = 1건). 넘으면 그날은 함께 걷기만 멈춰요.

### 함께 걷기에서 보이는 것
- 다른 사람: 나와 같은 모양에 옷 색만 다르고, 머리 위에 자동으로 지어진 닉네임(예: `졸린붕어37`, `꽁꽁빙어52`, `노곤한 판다27`).
- 화면 위: `지금 N명 함께 있어요`.
- 찌멍: 다른 사람의 **찌가 물 위에** 떠 있고 입질 때 움직여요. 누가 낚으면 그 자리에 **물보라 + 말풍선**, 월척·대물이면 모두에게 `🎉 ○○님 월척!`. 남이 앉은 좌대·구멍엔 앉을 수 없어요.
- 찜멍: 땀 빼기·눕기·열 식히기 자세, 계란 깨기·식혜 마시기 동작이 다른 사람에게도 보여요.

## 찌멍 (낚시)

- **조작**: PC는 WASD·방향키(Shift 달리기), 드래그로 시점 회전. 휴대폰은 왼쪽 아래 조이스틱. Space/E = 버튼.
- **흐름**: 좌대(또는 얼음 구멍)에 가면 `낚싯대 던지기` → 찌를 바라보는 중… → 꿈틀(예신) → 입질! 이때 `챔질` → 끌어올리기 → 기록 카드.
  - 붕어·황금 잉어는 찌가 **쑤욱 올라오고**(찌올림), 잉어·메기는 **쏙 들어가요**. 빙어는 톡톡 건드리다 살짝 잠겨요.
  - 입질 전에 누르면 헛챔질, 너무 늦으면 "미끼만 떼였네요".
- **한국 시간 연동**: 새벽·낮·노을·밤 하늘과 소리가 실제 시간에 맞춰 바뀝니다.
- **입질 타임**: 매일 05:00–05:30, 18:00–18:30 (한국 시간). 입질이 잦아지고 황금 물고기 확률 ↑.
- **도감 / 기록 카드**: 종류별 마릿수·최고 기록을 브라우저에 저장. 잡을 때마다 사진 + 길이 + 시간이 담긴 1080×1350 카드(인스타 4:5) 저장.
  - 붕어 30.3cm 이상은 **월척** 도장, 빙어 13cm 이상은 **왕빙어**.
- **어종**
  - 저수지: 붕어, 잉어, 메기(밤에 잘 나옴), 황금 잉어(희귀), 낡은 장화
  - 얼음 호수: 빙어, 산천어, 무지개송어, 황금 송어(희귀), 잃어버린 장갑
- **다른 낚시꾼**: 옆 좌대·구멍에서 가끔 고기를 낚고 말풍선을 띄워요. 가까이 가면 인사해요.
- **소리**: 전부 Web Audio 합성 — 물소리, 풀벌레·개구리(밤), 새(낮), 얼음 우는 소리·까마귀(얼음 호수), 찌 톡, 릴 감는 소리, 물 튀는 소리.

디버그용 주소 파라미터: `?t=18.2` (시간 고정), `?fast` (입질 빠르게).

## 찜멍 (찜질방)

- 온돌 휴게홀, 벽걸이 TV, 매점, 황토 불가마, 얼음방. 찜질복 + 양머리 수건 캐릭터.
- 동작: **땀 빼기**(불가마), **눕기**(매트, 위에서 내려다보는 시점), **계란 이마로 깨기**·**식혜 마시기**(매점), **열 식히기**(얼음방).
- 누적 카운터 "땀 n초 · 계란 n개 · 식혜 n잔"을 브라우저에 저장.
- 소리: 환풍기 웅웅, 멀리 TV 소리, 가끔 '띵동' 안내방송. 불가마 안은 먹먹하게.
